# Control de Mantenimiento de Aires Acondicionados

Sistema de escritorio para Windows para controlar el mantenimiento de aires
acondicionados: equipos, mantenimientos y alertas de próximos servicios,
agenda y contratos, órdenes de trabajo y cotizaciones en PDF, repuestos y
servicios, cobros con recibo y estado de cuenta, garantías, reportes y
respaldos. Funciona en una computadora o en varias compartiendo una base de datos.

## Descargar
Descargue el programa en la sección **Releases** (a la derecha) y abra
`MantenimientoAires.exe`. No necesita instalación.

Incluye 30 días de prueba con todas las funciones. Después requiere una
licencia.
